# 🚀 Universal Media Pro Saver (v2.5 PRO)

> **Phần mềm chuyên dụng tải Ảnh gốc (:orig), Video Full HD / 4K và chuyển đổi Âm thanh MP3 320kbps từ X (Twitter) & YouTube.**

---

| Nền Tảng | Loại Tệp | Chất Lượng Tối Đa | Tính Năng Đặc Biệt |
| :--- | :--- | :--- | :--- |

## 📱 Giao Diện Mobile & Desktop Chuẩn 100%

- 💎 **Thiết kế kính mờ cao cấp**: Tông màu Deep Slate kết hợp ánh sáng Neon Cyberpunk hiện đại.
- ⚙️ **Bảng Tùy Chỉnh Tối Ưu**: Cài đặt sẵn chất lượng MP3 / Video mặc định, tự động phân tích khi dán link, và quản lý YouTube Cookies.
- 📱 **Mobile-First Responsive**: Tối ưu hoàn hảo cho iPhone (Dynamic Island / tai thỏ) và tất cả các dòng smartphone Android.
- ⚡ **Tự động làm sạch URL**: Tự động lọc bỏ các tham số danh sách phát rườm rà (`&list=RD...`, `&start_radio=...`) để tải tức thì 1 video đơn lẻ.

## 🛠️ Hướng Dẫn Cài Đặt & Sử Dụng

### Cách 1: Chạy Trên Máy Tính (Khuyên Dùng)
Nhấp đúp chuột vào tệp:
```text
run.bat
```
*(Chương trình sẽ tự động mở trình duyệt tại `http://127.0.0.1:5000`)*

---

### Cách 2: Triển Khai Miễn Phí Trên Render.com (Online 24/7)
1. Fork hoặc đẩy repository này lên tài khoản GitHub của bạn.
2. Đăng nhập **[Render.com](https://dashboard.render.com/)** $\rightarrow$ Chọn **New Web Service** $\rightarrow$ Kết nối Repo này.
3. Cấu hình:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app`
4. Nhấn **Create Web Service** để nhận link web miễn phí truy cập từ mọi thiết bị!
